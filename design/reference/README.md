# Design reference

The six carousel screenshots DESIGN.md was measured from. They are the source
for the accent red, the canvas black, the card radius and stroke, the badge tab
geometry, the counter, and the type match — every value in DESIGN.md §1–§4 was
sampled from these pixels.

Kept in the repo so the measurements can be re-checked, and so a later change to
the design has something to be checked against rather than a description of
something nobody can see any more.
